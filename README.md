# kichwas-daggerheart-ui-refinement
My refinements to the Daggerheart UI. Changing a few things to my preferences.

At present this does two things:

1. Hide the spellcast trait from covering the character art. Instead it appears as a small text entry to the left of the header labels for class through ancestry.
2. Makes the fear track a fixed position element at the top center of the screen. It can still be hidden ir either icons or a progress bar, but it is smaller and locked in place.
